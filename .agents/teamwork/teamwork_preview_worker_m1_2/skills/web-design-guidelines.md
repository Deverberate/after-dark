Key rules for touch & interaction, focus states, accessibility:
- Touch targets: >= 44x44px min hit target on mobile / touch controls
- Interactive elements: visible focus with :focus-visible
- Never `transition: all`
- Scrollable regions: keyboard focusable (tabindex="0", role="region", aria-label)
- Never outline: none without replacement
